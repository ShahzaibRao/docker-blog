## What you'll find here

Hands-on Docker guides explained step by step — from your first `docker run` to Dockerfiles, Compose, volumes, networking and real-world labs. Written from practical experience, in easy Roman Urdu for beginners and students.

## Tech stack

- [Astro](https://astro.build) with the [AstroPaper](https://github.com/satnaing/astro-paper) theme
- Markdown posts in `src/data/blog/`
- Light & dark mode, tags, search, RSS included

## Writing a new post

1. Add a markdown file in `src/data/blog/`, e.g. `my-docker-guide.md`
2. Include frontmatter:

```yaml
---
title: "Post title"
description: "Short SEO description"
pubDatetime: 2025-09-26T00:00:00Z
tags: ["docker", "containers"]
---
```

3. Push to `main` — the site redeploys automatically.
